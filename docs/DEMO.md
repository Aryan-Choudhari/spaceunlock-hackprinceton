# Two-minute demonstration

Before presenting, run the app and Ollama, open the real Houston property, and verify the Evidence page and aerial image once. Cached evidence works without sponsor network access. Keep only this browser tab open.

**0:00–0:15 — The question.** “A building owner has $15,000. Which small combination of changes creates the most new possibilities?” Show the real address and the measured floor plan.

**0:15–0:35 — Evidence.** Point out the measured rooms and shared doorway connections in the commercial office scan. Open Evidence: Matterport supplies the measured candidate open room; the latest containing Vexcel parcel supplies the measured exterior hardscape area. Explain that doorway existence is observed, while passability and operating permission require confirmation.

**0:35–0:55 — Explicit assumptions.** Return to Planner. Click “Try a conditional demo scenario.” These checkboxes are hypothetical planning inputs, not verified permissions. Click “Find the best plan.” The local Ollama agent invokes deterministic tools.

**0:55–1:15 — The recommendation.** Show the $12,000 portfolio: activate an entrance, clear the route, reallocate the room and designate pickup space. Four uses pass conditionally. Removing Vexcel evidence makes distribution UNKNOWN. The proxy is measured candidate-room area for potential reuse, never carbon savings.

**1:15–1:40 — Adapt.** Click Compare budgets. Show $9,500 for three uses, then select $5,500 and rerun: the service desk remains a conditional option while room reassignment is unaffordable. Alternatively block the proposed access route to show route-dependent uses fail. Show the changed plan and trace.

**1:40–2:00 — Review and handoff.** Restore the original scenario, show its tool trace and explicit conditions, approve the draft and download the memo. “Every dollar, constraint and source is inspectable; the agent proposes, the engine checks, and the human decides.”

## Failure fallback

- Sponsor API unavailable: use the existing private cache, clearly labeled cached sponsor evidence.
- Cache unavailable: choose The Franklin Annex synthetic fixture; do not claim a live sponsor demonstration.
- Ollama unavailable: the app labels the deterministic fallback. Do not describe that run as an LLM agent run.
- No internet: reports, graph, optimizer and saved scenarios remain local. A previously cached aerial image also works.

## Claims to make precisely

- Two real sponsor layers affect modeled eligibility.
- A complete 64-portfolio search is transparent and reproducible.
- A local model selects tools; tools compute feasibility and cost.
- Conditional PASS is preliminary planning, not authorization.
- The prototype has no measured carbon-savings claim and uses estimated costs.
